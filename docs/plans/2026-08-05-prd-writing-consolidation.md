## 0. 背景与决策来源

PRD 阶段"页面 → 动作"写法过重，根因在 V2 动作正文硬约束（"必须回答交互四问" + "严禁任何要素名：标签"），不在标记格式。main（v1.0 已投产）的动作正文是轻量软约束。已对比 main 与 V2 的 skill / 规则 / 模板 / 示例，得出三部分结论并经认可：

- **一、已有（合并对齐）**：V2 已覆盖 main 意图，不重复造。
- **二、缺失（新增硬规则）**：main 有、V2 没有，需补进 `prd-writing-rules.md` §动作 的 5 条软约束。
- **三、缺失但建议不新增**：main 有、但与 V2 设计冲突/退步，明确不碰。

本文档把上述结论转成可执行步骤 + 验收标准，并补充 main 正反例的搬运/不搬运判定。
