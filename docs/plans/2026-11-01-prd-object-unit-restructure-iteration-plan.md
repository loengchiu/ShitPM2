- **复现结果**：同一事实在不同章节以近乎逐字相同的句子出现；删去任一处，该章节单独阅读就缺前提。
- **为什么不是表象级补丁**：两份 10-26 计划已分别调整叙述顺序和精简重复，换一份 Design 输入，同类重复仍会按分章结构再现。
