## 2. 发现的问题（均已修复）

### P2-1（按 P1 处理）：spm-design SKILL 结构被判据插入插坏

两层治理落地时，把"完整模式："标题和判据插入在"简单模式："标题与简单模式流程代码块之间，造成：①"完整模式："标题重复出现两次；②简单模式流程代码块与说明段落错误归属到插入的"完整模式："标题下。

- 与 R17 P1-1（design-state-format 章节插坏）同类——两层治理方案自己要求"不改语义只动措辞"，却在措辞插入时制造了 Markdown 结构损坏。
- 修复：删去插入的重复标题，判据归位（简单模式判据在简单模式标题下，完整模式判据移到原文完整模式标题后、代码块前）。修复后结构：简单模式→判据→简单模式流程→完整模式→判据→完整模式流程。
- 教训：批量插入"完成判据"时必须检查插入点是否跨标题边界（本次其余 9 个 SKILL 判据均在段落末尾、章节内，未跨标题——已逐处核验）。

### P2-2：spm-prd 阶段 D"禁止重新生成全文"约束在正面化时力度弱化

原句"禁止重新生成全文，禁止把模块正文压缩成摘要或改写已完成模块"被改写为"处理完成后不再改模块正文"，丢失"不重新生成全文"的明确禁令（该禁令与中断恢复段"不整篇重写 PRD"呼应，是分片流程防整篇重写的第二道约束）。

- 修复：补回"不重新生成全文、不把模块正文压缩成摘要或改写已完成模块"。

### P2-3：模板页面清单标题"页面清单（可选速览）"与提取逻辑精确匹配不符

`templates/design.md` 的页面清单标题带"（可选速览）"后缀，而 `_design_headings` 的 shared 判定是精确匹配 `title in ('页面清单', ...)` → 按模板格式书写的 design.md 在 `--module` 分片时不会提取页面清单共用部分（审计副本用无后缀标题所以未暴露）。

- 修复：shared 判定与过滤逻辑均改前缀匹配 `title.startswith('页面清单')`；新增回归断言（模板标题下共用部分被提取且按模块页面名过滤）。
