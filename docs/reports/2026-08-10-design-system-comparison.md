# 原型设计规范候选对比（业界验证过的规范）

> 背景：现有 `lib` 只给"有哪些零件、单个零件怎么写"，缺的是**布局/间距/尺寸/栅格规则**——零件放哪、多高多宽、间隔多少、页面怎么排。下面三个候选都自带这套规则，且都能**纯 Tailwind + CSS 变量落地，不引入构建**（保留现在"双击即看"的优势）。

---

## 你的缺口 = 规则层，不是组件层

| 缺失 | 现状 | 后果 |
|---|---|---|
| 间距标尺 | 无统一间距体系 | AI 随手 gap/padding，忽紧忽松 |
| 尺寸令牌 | 按钮高/输入框高/卡片内边距/圆角无定值 | 同零件每次长不一样 |
| 栅格/版式 | 壳层只讲概念，无内容区最大宽、无页面纵向顺序 | 页面结构漂移 |
| 页面组合模板 | 聚合/列表/表单/详情/看板五类页面怎么搭全靠临场发挥 | 同类页面长相不统一 |

下面三个方案按"规则严谨度 × 观感"排序。

---

## 候选 A：shadcn/ui（neutral 基调）

- **来源**（已验证可访问）：https://ui.shadcn.com/docs/theming
- **视觉基调**：现代 SaaS / App 风，近黑主色（`--primary: oklch(0.205 0 0)` ≈ `#333`），细 1px 边框，克制留白，无重阴影。就是你之前看到的 `sample-newlook.html` 那个调性。
- **令牌体系**：语义 CSS 变量（`background / foreground / card / primary / border / input / ring …`），圆角 `--radius: 0.625rem`（≈10px），并派生 `sm/md/lg/xl` 系列（`--radius-sm = *0.6` 等）。
- **间距/尺寸**：**沿用 Tailwind 默认刻度**，本身不另定义"卡片内边距 / 区块间距"具体档位。这是它的短板——规则层的"间距多大"仍靠默认，没有 Ant 那种强制标尺。
- **适合**：你已认可的观感；但规则严谨度不如 Ant。

---

## 候选 B：Ant Design v5（中后台企业风）

- **来源**（均已验证可访问）：
  - 布局 / 栅格：https://ant.design/docs/spec/layout
  - 字体 / 字阶：https://ant.design/docs/spec/font-cn
  - 全局令牌（控件高 / 圆角 / 内边距）：https://ant.design/docs/react/customize-theme
- **视觉基调**：经典中后台企业风，蓝色主色 `#1677ff`，白卡片 + 浅灰底 `#f5f5f5`，规整密集。这就是你说的"后台感"来源——但它是被千万人验证过、最严谨的规则体系。
- **间距体系（8px 网格，所有数都是 8 的倍数）**：
  - `padding`：16 / 12 / 8 / 4（基础 / SM / XS / XXS）
  - `margin`：16 / 8 / 4
  - 栅格：24 列，gutter 固定，内容区按 8 的倍数取舍
- **控件尺寸**：高度 `24(sm) / 32(默认) / 40(lg)`；圆角 `4 / 6 / 8`；边框 `1px`
- **字号**：基准 `14 / 行高 22`；字阶 10 档；字重只用 `400 / 500 / 600`；文本色 `#000000E0` / 二级 `#000000A6` / 禁用 `#00000040`
- **布局尺寸**：顶栏 `64` / 二级 `48`；侧栏 `200+8n`；统一画板 `1440`、内容宽 `1168`
- **适合**：规则最全最严谨，正好补你缺的"间距/尺寸/栅格"；但默认蓝色企业风可能不是你要的观感（你明确嫌过"后台感"）。

---

## 候选 C（推荐）：用 Ant 的"规则"，套 shadcn 的"皮"

- 你的**缺口是规则**（间距/尺寸/栅格）——Ant 最严谨，直接抄它的令牌数值。
- 你的**偏好是中性克制观感**——shadcn neutral 最贴，把 Ant 的蓝主色换成近黑/中性、边框削细、底色保留干净白/浅灰。
- **结果**：一套有业界验证间距标尺 + 控件尺寸 + 栅格的设计系统，但长相是你认可的现代中性风。两者都是纯 Tailwind / CSS 变量，无构建。
- **样张**：`output/prototype/sample-hybrid.html`（同内容，应用 Ant 间距令牌 + 中性皮），双击即可看。

---

## 候选 D：IBM Carbon（数据密集企业风）

- **来源**（间距网格 / color token 角色均已逐个验证；spacing/type 用 Carbon 公开稳定令牌体系）：
  - 2x Grid：https://carbondesignsystem.com/elements/2x-grid/overview
  - Themes / Tokens：https://carbondesignsystem.com/elements/themes/overview
- **视觉基调**：专业、克制、高密度（IBM 技术冷感），**直角/极小圆角**（默认 radius 0，最显眼信号），主色 `#0f62fe`，IBM Plex 字体，主按钮右侧带箭头图标（Carbon 招牌）。
- **间距体系（2x Grid，mini unit 8px）**：spacing scale `2/4/8/12/16/24/32/40/48/64/80/96/128 px`（spacing-01~13）；标准 padding `16px`、gutter `32px`。
- **控件尺寸**：按钮高 `48(默认)/32(sm)`；输入框高 `40`；边框 `1px`；圆角 `0`（或 ≤2px）。
- **字号（productive）**：基准 `14/20`；字阶 heading-01~07：`14/18 · 16/22 · 20/26 · 28/36 · 32/40 · 42/50 · 54/64`；caption/label `12/16`；字重 `400/600`。
- **颜色（White theme）**：`background #fff` / `ui-01(tile) #f4f4f4` / `border #e0e0e0` / `text-01 #161616` / `text-02 #525252` / `interactive(btn) #0f62fe` / `error #da1e28` / `success #198038`。
- **样张**：`output/prototype/sample-carbon.html`（含数据看板页 / 列表页 / 表单页，按你确认的 7 类骨架渲染）。
- **适合**：数据密集型后台（表格/图表/分页）标杆；但「挤」、冷，不如 Arco 那么「轻松大方」，可能不是你要的日常观感。

## 页面模板清单（B 端顶级页面，最终锁定 7 类）

你是 B 端 PM，常用页面锁定为以下 **7 类顶级页面**（2026-08-10 拍板）：
**聚合页 / 列表页 / 表单页（含分步向导变体）/ 详情页 / 数据看板页 / 结果页 / 异常页**。
规则层必须给每类一个**固定组合骨架**（AI 照抄，不再临场发挥）。弹窗、空状态、加载态归"组件级模式"单独写，不占顶级。

> 注：「看板页」经确认 = **数据看板**（指标卡 + 图表），**非**任务看板（Kanban 泳道）。任务看板如后续需要再单列。

| 页面类型 | 固定骨架（自上而下） |
|---|---|
| 聚合页（Workbench） | 标题区 → KPI 卡片行（4 列）→ 图表/列表区块（2 列或全宽） |
| 列表页 | 标题区（标题+副标题+右上主操作）→ 查询卡（一行条件+查询/重置）→ 表格卡（表头/行/分页条） |
| 表单页（含分步向导变体） | 标题区 → 表单卡（按分组，两列，长字段单列占满）→ 底部右对齐操作条；分步时用步骤条替代单屏 |
| 详情页 | 标题区（含返回）→ 信息卡（标签-值两列）→ 关联/子表卡 |
| 数据看板页 | 标题区 → 指标卡行（4 列，含同比箭头）→ 图表卡（柱状/折线/饼）+ 异常明细表 |
| 结果页（Result） | 整页居中：状态图标 + 标题 + 描述 + 操作按钮（成功/失败/批量结果反馈） |
| 异常页（Exception） | 整页居中：大号状态码（403/404/500）+ 说明 + 返回操作；区别于嵌入的空状态 |

Ant Design / Arco 都为这 7 类提供了成熟模板，抄它们的组合骨架最稳。
