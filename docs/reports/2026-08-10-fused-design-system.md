# 融合设计规范：公司《内控类系统设计规范》× Arco Design

> 目的：解决 spm-prototype「缺设计系统（布局/间距/尺寸/栅格规则）」的痛点。
> 读法：**公司规范是强制覆盖层**（凡它定义了的，优先于 Arco）；**Arco 是补充层**（公司没定义的，用 Arco 补齐）。
> 来源：公司规范 `https://www.kdocs.cn/l/csznrjalCxN8`（内控类系统设计规范.ksheet，147 条）；Arco Design 公开令牌体系。

---

## 1. 重要发现（先看清再落位）

1. **公司规范的视觉令牌是 Element UI 血统**：`#606266`(次文本) / `#dcdfe6`(边框) / `#f5f6f7`(移动背景) / `#FAFAFA`(表头底) / `#aeadb2`(占位) 全是 Element 默认色；备注出现 `bladex`（基于 Element 的后台框架）。**若追求与公司真实技术栈最大一致，Element Plus 才是"天然"基底。**
2. 但按你的指令，本规范以 **Arco 为结构/补充基底 + 公司令牌强制覆盖**。最终视觉 = 公司配色/字体/尺寸 + Arco 的间距标尺与页面骨架。
3. 公司规范**覆盖很全的是「功能/交互/集成」规则**（数据来源、导入校验、删除二次确认、单点登录、流程引擎等），**薄弱的是「纯视觉设计系统」**：没有完整间距标尺、没有字阶、没有阴影体系、没有七类页面的「组合骨架」（只有零散组件规则）。这正是 Arco 补的。

## 2. 融合后设计令牌（单一事实源）

### 2.1 颜色（公司强制，覆盖 Arco）
| 角色 | 值 | 用途 | 来源 |
|---|---|---|---|
| 主色 primary | `#1E6DEA` | 按钮/链接/选中/主操作 | 公司（覆盖 Arco `#165DFF`） |
| 辅色-成功 | `#65c748` | 成功状态 | 公司 |
| 辅色-警告 | `#f49b2f` | 警告状态 | 公司 |
| 辅色-错误 | `#f55554` | 错误/删除 | 公司 |
| 文字-主 | `#252525` | 标题/正文/图标 | 公司 |
| 文字-次 | `#606266` | 次要文字/列表行 | 公司 |
| 文字-占位 | `#aeadb2` | 提示/占位/时间 | 公司 |
| 边框 | `#dcdfe6` | 输入框/分割线/卡片描边 | 公司 |
| 表头底 | `#FAFAFA` | 列表表头背景 | 公司 |
| 页面背景 | `#f1f5f8` | PC 内容区底色 | 公司 |
| 系统名色 | `#15499a` | 系统名称（logo 旁） | 公司 |

### 2.2 字体（公司强制）
- 字体族：`"Source Han Sans CN","思源黑体","PingFang SC","Microsoft YaHei",sans-serif`
- **行高规则（公司硬规定）**：行高 = 字号 × 1.5
- 系统名称 24px / 模块标题 18px 加粗 `#252525` / 弹窗标题 20px 加粗 `#252525`
- 注：思源黑体本地未必安装，离线回退到 PingFang/微软雅黑；团队以金山文档在线版为准，线上可确保字体。

### 2.3 间距标尺（Arco 补充，4px 基准；公司 16/24 并入）
`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 px`
- 内容区内边距 = **16px**（公司强制）
- 表单上下字段间距 = **24px**（公司强制）
- 图标与文字间距 = **14px**（公司强制，金刚区）

### 2.4 圆角（公司强制 10px 内容区；控件 8px）
- 内容卡 / 页面容器圆角 = **10px**（公司强制，覆盖 Arco 偏小圆角）
- 按钮 / 输入框圆角 = **8px**（取 Arco 近值，保持克制）

### 2.5 阴影（Arco 四档，公司无 → 直接采用 Arco）
`--shadow-1/2/3/4` 极淡层级阴影，用于卡片浮起/弹窗/下拉。公司规范无阴影要求，用 Arco 保证层次。

### 2.6 字号阶梯（以公司 14 基准 + Arco 字阶）
`12 / 14(基准) / 16 / 18(模块标题) / 20(弹窗标题) / 24(系统名) / 30 / 38`
- 正文/列表/表单统一 **14px**；次要/占位 12–13px；标题按上表。

### 2.7 布局尺寸（公司强制）
- 侧边栏宽度 **240px**（图标+文字，16px，`#252525`）——覆盖 Arco 232/256
- 顶部菜单高度 **64px**（右上放 个人中心/操作手册/在线）——覆盖 Arco 48/56
- 金刚区图标 **64×64，圆角 14px**，图标与文字间距 14px（PC）

### 2.8 组件尺寸（公司强制，覆盖 Arco）
| 组件 | 尺寸 | 来源 |
|---|---|---|
| 搜索框高度 | 36px | 公司 |
| 按钮高度 | 36px（图标+文字 14px） | 公司 |
| 表头高度 | 40px，文字 14px `#252525`，底 `#FAFAFA` | 公司 |
| 列表行高 | 50px，文字 14px `#606266` | 公司 |
| 表单单元格高 | 36px，14px | 公司 |
| 弹窗标题 | 20px 加粗 `#252525`，右上角仅 icon 无文字 | 公司 |
| 列表空值 | 显示 `--` | 公司 |
| 列表操作 | 图标+文字 14px；删除必须二次确认 | 公司 |

## 3. 七类页面骨架（Arco 提供组合，套公司令牌）

公司规范只有零散组件规则，**没有页面级组合骨架**——这是 Arco 补的最大价值。

| 页面类型 | 固定骨架（自上而下，套公司令牌） |
|---|---|
| 聚合页/首页 | 顶部菜单(64) → 侧栏(240) → 内容区(间距16/圆角10) → 金刚区(64×64) → 待办 → 数据看板 |
| 列表页 | 模块标题区(18bold) → 筛选搜索卡(搜索框36/表单间距24/搜索+清空) → 表格卡(表头40/#FAFAFA,行50/#606266,空"--",操作栏图标+文字14,删除二次确认) → 分页 |
| 表单页 | 标题区 + 返回(右上) + 表单卡(单元格36/上下间距24/必填*/字数限制标注) + 底部居中 取消·保存/提交（**无**图标+文字） |
| 详情页 | 标题区(返回) → 信息卡(标签-值两列) → 关联/子表卡 → 图片点击预览 |
| 数据看板页 | 指标卡行(4列,同比箭头) → 图表卡(柱状/折线/饼) + 异常明细表（公司仅说"按不同数据排版"，骨架用 Arco） |
| 结果页 | 整页居中：状态图标 + 标题 + 描述 + 操作（成功/失败/批量结果） |
| 异常页 | 整页居中：大号状态码(403/404/500) + 说明 + 返回（区别于嵌入空状态） |

## 4. 组件级模式（公司强制交互 + Arco 视觉）

- **删除**：所有删除必须二次确认弹窗（公司硬规）。
- **表单提交**：按字段校验，不符合对应字段错误提示；成功/失败弹窗有时限自动消失。
- **导入**：提供 Excel 模板（首行字段名、必填加`*`、次行红字示例）；上传进度条；成功提示条数、失败逐行字段提示。
- **弹窗**：右上角仅 icon 关闭（无文字）；底部 取消/确认（无图标+文字）。
- **逻辑删除**：无特殊需求全部逻辑删除（公司）。
- **单点登录**：统一 OA 单点登录，页面展示接口返回提示。
