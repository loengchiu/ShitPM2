## T-1 建立数据口径闭包唯一规范

### 1. 规范落点与权威单源

- **新建权威规范文件**：`references/data-definition-rules.md`
  - **触发边界**：明确重要数据结果（影响业务决策、判断、核算、对账、下钻、导出）必须触发；普通单源录入、自增 ID、纯静态展示免除复杂闭包。
  - **四档递增责任**：
    - 第一档（直接数据）：权威数据源实体与字段 + 空值回显；
    - 第二档（派生数据）：依赖字段 + 转换/换算规则 + 异常空值；
    - 第三档（汇总统计）：统计对象 + 组织/权限 + 时间起止开闭 + 分子分母 + 状态白名单/排除项 + 去重唯一键 + 零值兜底 + 刷新时效 + 下钻导出一致性（统一写作九项要素）；
    - 第四档（周期结算）：账期锚点 + 取数版本 + 完整分步公式 + 过程与最终精度 + 尾差平衡机制 + 重算锁定 + 正常例与边界例。
  - **同名同口径原则**：同一系统/模块内同名指标在卡片、列表、趋势、下钻、导出中默认必须同口径；存在差异必须显式重命名并设立差异说明。
  - **决策簇原则**：发现关键数据口径事实缺失时，禁止在 PRD 阶段自作主张推测拍板，禁止碎片化逐字段多轮追问；必须聚合成决策簇一次性向上游暴露为 pending decision。
  - **低影响推断与高影响未知边界**：明确千分位、货币符号、日期格式等低影响推断与状态范围、分母、公式等高影响未知的红线。
  - **正常例与边界例适用条件**：仅在第四档及复杂分步计算中且 Design 已明确规则时提供，严禁 PRD 凭空编造假想规则。
  - **章节分工与落点原则**：单业务模块自包含；`4.x.5` 收敛公共口径与公式；`4.x.6` 承接页面应用；`4.x.7` 仅保留控件属性与来源索引，严禁口径压缩在字段表；`4.x.9` 放验收用例。
  - **“系统统计/系统计算”语句约束**：严禁作为唯一描述；仅在正文已定义完整口径时才可作为字段属性简写。
  - **八类试读问题与九项要素关系**：八类试读问题作为 Review 审查与试读验收的统一提问口径，检验九项写作要素是否落实，消除两套近义清单。
