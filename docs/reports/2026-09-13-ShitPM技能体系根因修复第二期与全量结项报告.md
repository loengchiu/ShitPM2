## 2. T-4 详细执行证据：Prototype Fixture 与共享层边界

### 2.1 根因解决与身份定位（D-4 A 决策落地）
- **旧版表象**：模板内置 demo 使用共享组件，但 `prototype-consistency-check.py` 将 `modules/demo/` 列入 `EXCLUDED_SOURCE_PREFIXES = ("modules/demo/",)` 静默排除。导致门禁弱化、示例脱离规则、最易被 AI 模仿的代码缺少锚点约束。
- **修复措施**：
  1. **显式标注受检 Fixture 并如实陈述受检面**：
     - 创建 `templates/prototype-vite/src/modules/demo/README.md` 与更新 `templates/prototype-vite/README.md`，明确其为**受检 Fixture**（Checked Fixture）；
     - 如实界定受检面：受 `prototype-shared-guard.py`（G1~G5）全量守护，严禁直接引用未经封装的第三方图标、外部 CSS 或重复版权（真实受检通过）；受 `prototype-consistency-check.py` 源码扫描全量覆盖，不再作为未解释路径静默跳过，登记为 `fixture_files` 与 `fixture_routes`，不夸大宣称存在未实现的锚点层级检查；
  2. **消除静默路径排除**：将 `prototype-consistency-check.py` 的 `EXCLUDED_SOURCE_PREFIXES` 置空（`()`），新增 `FIXTURE_SOURCE_PREFIXES = ("modules/demo/",)`；源码扫描全量覆盖 demo 目录，不跳过任何源码文件；
  3. **收敛 `_is_fixture_route` 为单一严格判据（防假绿）**：
     - 移除脆弱的 `module ∈ {样张, demo...}` 与 `path ∈ {/gallery, /detail...}` 启发式匹配；
     - 收敛为**「`component` 是否解析到 `fixture_files`」单一判据**：仅当路由指向的组件确实来自已识别的 fixture 文件时才判定为 fixture 路由，彻底避免业务项目中名为 `demo` 的模块或 `/detail` 路由被静默跳过页面对账；
  4. **补齐规范示范锚点**：
     - `DetailDemo.jsx`：添加根元素 `data-page="商户详情"`、卡片 `data-block="基本信息"` / `缴费信息` / `收款明细` / `备注` / `页面操作`、标签 `data-state="已缴清"`、操作按钮 `data-operation="编辑"` / `打印` / `导出账单`；
     - `FormDemo.jsx`：添加根元素 `data-page="出库申请"`、卡片 `data-block="审批流"` / `出库信息` / `页面操作`、表单控件 `data-field="资产类别"` / `出库数量` / `使用部门` / `期望出库日期` / `出库类型` / `经办人` / `出库原因` / `备注`、按钮 `data-operation="重置"` / `取消` / `提交申请`。

## 4. T-6 详细执行证据：测试证据分层

### 4.1 Pytest 标准收集与配置
- **问题根因**：原测试脚本均采用 `test-*.py`（连字符命名）且部分脚本仅包含 `if __name__ == '__main__': main()`，导致 pytest 默认规则（`test_*.py`）下收集数为 0（exit code 5）。
- **解决动作**：
  1. 创建仓库级 `pytest.ini`：
     ```ini
     [pytest]
     testpaths = scripts/python
     python_files = test-*.py test_*.py
     python_functions = test_*
     ```
  2. 为原先只提供 CLI 入口的 8 个测试脚本补齐 `def test_*() -> None:` 包装入口，内部断言 `main() == 0` 或捕获合规退出码；
  3. 保留所有脚本的 `if __name__ == '__main__':` CLI 直跑能力。

### 4.2 双层测试实测对比

| 测试模式 | 覆盖文件 | 收集/执行数量 | 运行耗时 | 退出码 | 语义保护边界 |
