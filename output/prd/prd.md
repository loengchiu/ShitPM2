# 团队周报收集工具 - 产品需求文档

## 一、概述
### 1．产品目标
为团队提供周报填写、汇总和归档的标准化工具。

## 二、角色与权限
| 角色 | 权限 |
|------|------|
| member | 填写/查看/撤回自己的周报，查看团队汇总 |
| admin | 查看所有成员周报，导出周报 |

## 三、页面说明
### page-1 我的周报列表
展示当前用户的所有周报。

### page-2 填写周报
新建或编辑周报。

### page-3 团队汇总
按周查看团队所有成员的周报。

### page-4 历史归档
按周归档查看历史周报。

## 四、详细需求说明
### 周报填写
用户可新建周报，填写本周完成、下周计划等信息。

## 五、数据字典
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| report.id | string | 是 | 周报编号 |
| report.submitter | string | 是 | 提交人 |
| report.week | string | 是 | 所属周 |
| report.this_week | text | 是 | 本周完成 |
| report.next_week | text | 是 | 下周计划 |

## 六、权限汇总
| 页面/对象 | member | admin |
|------|------|------|
| 我的周报列表 | 查看自己的周报、撤回草稿或待提交周报 | 查看全部周报 |
| 填写周报 | 新建、编辑、提交自己的周报 | 代查看，不参与填写 |
| 团队汇总 | 查看团队汇总 | 查看团队汇总、导出周报 |
| 历史归档 | 查看已归档周报 | 查看全部归档周报 |

按钮级口径：

- `member`：可使用"新建周报"、"编辑"、"提交"、"撤回"；仅作用于自己的周报
- `admin`：可使用"导出周报"；不可编辑成员周报正文

## 七、状态机
draft → submitted
