# 名词说明章节写法

> 术语表的结构位置、表头和格式由模板与确定性脚本处理；本文件只规定术语选择和定义质量。脚本负责候选术语提取、分类、排序、去重、表头和长度检查。

<!-- context:prd-writing-glossary:start -->
## 收录范围

入 glossary：角色术语（如项目主审）、业务专有名词（如上报告、底稿、挂销号）、字面易误解的状态术语、系统特有概念。

不入 glossary：动作名、按钮文案、提示文案、页面名、无歧义的通用技术术语。

## 数据来源

只从确认版 `output/design/design.md` 提取并集中整理，不新增定义。

## 定义质量

- 一句话定义，不超过 50 字，不写来源；
- 只说明“是什么”，不解释为什么这样命名；
- 层级关系用“属于 X 的 Y”或“X 的子类”表达；
- 角色名、状态名是术语来源；动作名、按钮名不入表。
