# PRD 场景覆盖自检清单

> 本文件是 PRD 写作过程中的场景自检清单。
> 每个动作写完后，按此清单检查是否覆盖关键场景；不存在的场景跳过，未覆盖的必须补充。

## 自检维度

### 数据展示
- 静态内容用双引号标明
- 动态内容说明数据来源
- 超长文本处理方式（截断/换行/滚动/悬停）
- 空状态文案

### 按钮与操作
- 可点击/不可点击条件
- 点击反馈（加载动画、防抖、置灰）
- 操作成功后的变化
- 操作失败提示

### 表单与输入
- 输入限制（字符类型/长度/格式）
- 校验时机（实时/失焦/提交时）
- 错误提示文案

### 列表与加载
- 加载方式（分页/无限滚动）
- 加载中提示
- 无数据/加载失败/加载完毕状态

### 弹窗
- 触发/关闭方式
- 点击遮罩层是否关闭
- 多弹窗优先级和父子关系

### 异常与降级
- 网络异常处理
- 权限不足提示
- 关键功能降级

### 边界
- 数值边界值
- 列表数据量上限
- 状态临界值
- 并发冲突

## 使用方式

每个动作写完后逐项检查。存在的场景必须覆盖；不存在的场景跳过。未覆盖的必须补充。
