# Prototype 页面类型与标准结构

> 本文件在生成或评审业务页面时读取。它定义 7 类页面 + 公共页的标准结构（从上到下的固定顺序）、每类的必须项与禁止项、官方规范章节书签和锚点约定。
> 权威顺序：`references/design-sources/ant-design-official/*.md`（尺寸/间距/控件规格）> `references/prototype-shell.md` + `prototype-writing.md` 白名单 6 条（壳层习惯）> 本库其他约定。颜色一律按 `tablerTheme.ts`（Tabler 体系），不写死色值。
> 页面骨架的历史来源：`prototype-component-behavior.md` §4–§9（2026-09-11 迁入本文件并按 v3 口径改写；原「起步模板」实现已随 ProComponents 卸载删除，本文件即其文字版替代）。

## 一、总则

### 分类判别

生成页面前先判类，再按对应章节实现；一类页面只允许一种筛选形态：

| # | 页面类型 | 判别条件 |
| :-- | :-- | :-- |
| 1 | 标准查询表格 | 列表页且筛选项 ≥5 |
| 2 | 轻量工具栏表格 | 列表页且筛选项 ≤4 |
| 3 | 批量操作表格 | 类 1 或类 2 + 行选择与批量动作 |
| 4 | 多步骤长流程表单 | ≥3 步或步骤有先后依赖 |
| 5 | 配置类 / 分组表单 | 单页多分组、无步骤依赖 |
| 6 | 对象详情页 | 只读呈现单对象 |
| 7 | 看板页（概览/驾驶舱） | 一屏指标 + 图表汇总 |
| — | 公共页 | 登录 / 个人中心 / 结果页 / 异常页（403/404/500）|
| — | 任务看板页（原 Kanban） | Trello 式拖拽任务板；**不属于 7 类**，按公共页处理 |
| 横切 | 快照 / 只读态 | 展示已归档版本或不可再编辑的记录，可叠加在任意一类上 |

### 对存量的两条让路（不得改回去）

1. **空字段占位一律用 `—`**，不用"未填写"（存量全库统一口径，规范向存量让路）。
2. **表格横向滚动 / 钉列只修真的会溢出的页**：数据列宽度确实超过容器时才加 `scroll={{ x }}` 与首末列 `fixed`，不全量套用（存量折中口径）。

### 锚点约定

`prototype-consistency-check.py` 只从真实 JSX 标签属性提取 `data-*` 锚点，字符串里的 HTML 模板不算事实：

- 页面根元素挂 `data-page="<页面名>"`。
- 区块（搜索卡 / 表格卡 / 分组卡 / 概览卡）挂 `data-block="<区块名>"`。
- 字段锚点挂 `data-field="<字段名>"`，写在控件（Form.Item 内控件）或表格单元格 / 表头自定义渲染元素上；antd `columns` 数组对象不是 JSX 标签，**不得**把锚点写进列配置对象。
- 操作按钮挂 `data-operation="<操作名>"`。
- 状态锚点挂 `data-state="<状态名>"`。
- 锚点名称与 Design 事实源用词逐字一致；锚点是防幻觉机制，缺失或改写会直接削弱一致性裁决。

## 二、类 1 标准查询表格（筛选项 ≥5）

**标准结构**（从上到下）：内页标题 + 右上返回 → 独立搜索卡（筛选项网格 2~3 列，`展开/收起`，`查询`/`重置` 靠右）→ 表格卡（卡头 = 标题 + 数量徽章 + 右侧工具栏；表内 = 长文本省略）→ 分页（靠右）→ 底部通栏操作栏 → 操作栏上方版权行。

**必须**：

- 筛选项 ≥5 时独立成卡且**默认折叠**（`展开` 后显示全部）；展开状态不影响已填筛选值。
- 卡头三要素：实体标题、数量徽章、主操作（≤1 个，其余进下拉）。
- **有分页且显示总条数**（`showTotal`）；`查询`/`重置` 后页码复位第 1 页；`重置` 清空全部输入并重新拉取。
- 长文本列 `ellipsis` + 悬浮显示全文；表头不换行；状态/短列有最小宽度。
- 内页标题右上返回（不在底部操作栏放返回）。
- 筛选项的字段、枚举值与默认值必须来自 Design，不自造筛选项。
- 表头固定：数据行超过一屏时固定表头；一屏内可展示完的短表格不固定。固定列（`fixed`）仅按总则让路条款处理。

**禁止**：把 ≥5 个筛选塞进单行；表头换行；列挤不下还不上横向滚动；分页状态被筛选操作丢失；无 Design 依据开放密度切换/列设置。

**官方章节书签**：`components_Table.md` §筛选组件使用规则、§列表页顶部筛选、§表格样式规范、§分页规范、§表格卡头部表达。

**锚点约定**：搜索卡 `data-block`；每个筛选控件 `data-field`；表格卡 `data-block`；数量徽章随卡头；行内操作按钮 `data-operation`。

## 三、类 2 轻量工具栏表格（筛选项 ≤4）

> **净新增要求**：存量 0 例。命中本类必须真的用单行工具栏，不得退回独立筛选卡；只约束新生成页面，不回溯改存量。

**标准结构**：内页标题 → 单行工具栏（左：搜索框 + ≤4 个筛选；右：刷新/列设置 + 主操作按钮）→ 表格卡 → 分页 → 底部操作栏。

**必须**：≤4 个筛选与工具栏同一行；主操作按钮带图标 + 文字；页签用于同一实体的子集切换时，页签项必须来自 Design 已定义的分类，页签切换与筛选叠加时页码复位第 1 页；表头标题、数量徽章与表体左对齐线一致。

**禁止**：为 ≤4 个筛选单独开一张搜索卡；同一页面两种筛选形态并存；行内换行出现第二行工具栏。

**官方章节书签**：`components_Table.md` §工具栏布局、§表格卡头部表达、§卡内顶部 Tab Strip。

**锚点约定**：工具栏容器 `data-block="工具栏"`；筛选控件 `data-field`；主操作 `data-operation`。

## 四、类 3 批量操作表格

**标准结构**：同类 1 或类 2 + 表头复选列 → 选中后出现的批量提示条（"已选 N 项" + 批量动作 + `取消`）→ 批量动作二次确认。

**必须**：无选中时**不渲染**提示条；批量动作名称与可用条件来自 Design，不得把单行操作搬进批量区；危险动作（删除）用危险色按钮 + 二次确认，确认文案写清影响范围；操作完成清空选择；全选/反选用表格内置选择语义，不自造"全选当前页/全部"语义（除非 Design 明确）。

**禁止**：无确认直接执行删除；批量选择与分页状态互相干扰；无 Design 授权新增批量动作。

**官方章节书签**：`components_Table.md` §4 批量操作表格、§工具栏布局。

**锚点约定**：批量提示条 `data-block="批量操作"`；每个批量动作 `data-operation`。

## 五、类 4 多步骤长流程表单

> **净新增要求**：存量 0 例（无 `Steps`），实现难度最高。步骤数量、名称与归属必须来自 Design 的流程定义。

**标准结构**：内页标题 → 纵向步骤条 → 当前步（分区标题 + 字段，label 在上）→ 单步 `上一步`/`下一步` → 末步汇总卡 + 确认项 → 底部操作栏（`保存草稿` / `提交`）。

**必须**：单步校验拦截（校验失败停留原步骤并内联提示，不允许最后一步统一报错）；跨步回退不丢已填数据；草稿暂存（不推进流程状态、不替代正式提交）；末步汇总可见、确认项未勾选不得提交；提交按钮文案在末步由「下一步」变「提交」；角色导致步骤增减时必须能追到 Design 流程分支，追不到按高影响未知处理。

**禁止**：把所有步骤塞成一张长表单；校验失败无提示；合并跨角色的审批环节；用按钮文案表达权限（权限用禁用/隐藏语义）。

**官方章节书签**：`components_Form.md` §分步表单选型、§3 竖向分步表单。

**锚点约定**：步骤条 `data-block="流程步骤"`；每步字段 `data-field`；`保存草稿`/`提交`/`上一步`/`下一步` 均 `data-operation`。

## 六、类 5 配置类 / 分组表单

**标准结构**：内页标题 → 多个分组卡（每卡：标题 + 说明 + 字段网格，label 在上）→ 底部操作栏（`取消` / `保存`）。

**必须**：每个分组有标题与说明；分区标题即 Design 区块名，同类字段成行、跨语义字段不混排；字段宽度按官方档位（短字段不铺满整行），文本域整行；表单不渲染自己的提交按钮，统一由底部操作栏通过 Form 实例触发；必填/格式/范围校验用字段规则内联反馈；只读字段用只读控件或文本表达。

**禁止**：一张巨卡塞进所有字段；字段宽度随意；分区内部出现第二套提交入口；用「（必填）」「（只读）」等解释性文案代替控件语义；用禁用控件冒充只读。

**官方章节书签**：`components_Form.md` §4 嵌入模式表单、§输入框宽度规范、§操作按钮位置。

**锚点约定**：分组卡 `data-block`；字段 `data-field`；`保存`/`取消` `data-operation`。

## 七、类 6 对象详情页

**标准结构**：内页标题（标题 + 状态标签 + 右上返回）→ 概览卡（关键字段 + 主要操作）→ 分组卡片描述列表（字段按 Design 区块分组，一组一卡）→ 关联数据（表格/列表，按需）→ 底部操作栏。

**必须**：

- 首屏有**概览卡**（关键字段 + 主要操作打头）。
- **状态标签位于内页标题旁**，不放在字段行里。
- 空字段统一显示 `—`（总则让路条款，不用"未填写"）。
- 只读展示不出现可编辑控件；需要跳转/下钻的字段用链接或按钮，并按 Design 角色与可用条件控制可见性。
- 状态用标签表达；长文本区块整行展示。

**禁止**：详情页做成可编辑表单（编辑走弹窗/抽屉）；描述列表单元格内堆叠行内操作；空值留白或用 `—` 以外的自造符号。

**官方章节书签**：`components_DescriptionList.md` §描述列表选型、§3 分组卡片描述列表、§布局规则。

**锚点约定**：概览卡与每组卡 `data-block`；字段对 `data-field`；状态标签 `data-state`；操作栏按钮 `data-operation`。

## 八、类 7 看板页（概览 / 驾驶舱）

> **近乎净新增**：存量无图表库引入。图表用 ECharts 实现，视觉适配按 `design-sources/ant-design-official/ADAPTATION.md`（官方图表规范基于 `@ant-design/charts`，本库换算为 ECharts 等效配置）。

**标准结构**：内页标题 + 时间范围 → 指标卡行（3~5 个等宽）→ 图表区（2~4 个，2 列网格）→ 待办/异常列表 →（无底部操作栏，或仅"导出"）。

**必须**：一屏内可看完；指标卡等宽栅格排布（非 flex 均分凑数）；每个图表有标题与时间范围；无数据时空态占位。

**禁止**：**下钻**（用户明确不做，要做会专门说）；超过 4 个图表堆成长页。

**官方章节书签**：`components_Chart.md` 全篇 + `layout.md` §主内容区规范 + `ADAPTATION.md`（ECharts 适配）。

**锚点约定**：指标卡与图表卡 `data-block`；时间范围选择器 `data-field="时间范围"`。

## 九、公共页

**范围**：登录页、个人中心、结果页（提交成功/失败）、异常页（403/404/500）、任务看板页（原 Kanban，已移出 7 类）。

**标准结构**：登录页无三栏壳层、居中卡片；其余与业务页同壳层。

**必须**：异常页给出返回入口；结果页给出下一步动作；登录表单按官方登录规范。

**禁止**：登录页套业务壳层；异常页无出口。

**官方章节书签**：`components_Form.md` §6 登录表单 + `layout.md`。

**锚点约定**：页面根 `data-page`；表单控件 `data-field`；动作按钮 `data-operation`。

## 十、横切模式：快照 / 只读态

**触发**：页面展示的是已归档的历史版本或不可再编辑的记录（存量 `SnapshotBar` 实践：prepare / implementation / report / rectify 共 6 页在用）。可叠加在任意一类页面的只读形态上。

**标准结构**：顶部只读横幅（`sticky` 顶栏，浅色底 + 图标 + 文案"归档快照 · 只读" + 快照时间 / 归档人；快照失效时转警示色）→ 内页标题 → 正文（同所属类的只读形态）→ 底部操作栏（无编辑类按钮，仅 `返回` / `导出`）。

**必须**：只读横幅在任何滚动位置都可见（`sticky top`）；正文所有编辑控件转为纯文本展示；失效快照给出明确原因。

**禁止**：把只读态做成"全部字段 `disabled` 的表单"；横幅随内容滚走。

**官方章节书签**：官方手册无对应章节，本库自有约定（存量实践反哺规范）。

**锚点约定**：横幅 `data-block="快照横幅"`；快照时间/归档人 `data-field`。

## 十一、适用验收

- 只核对当前任务命中的页面类型与真实消费者；不存在的场景（弹层、固定列、批量、快照）标记不适用，不制造页面凑验收。
- 页面类型的验收以「是否按本文件标准结构实现、必须项齐备、禁止项为零」为第一判据；结构偏离或缺失必须项记入评审待修项。
- 尺寸、间距、字号、阴影一律按官方默认（主题不覆盖），颜色按 Tabler；构建、路由、console 等通用完成门槛遵循 `skills/spm-prototype/SKILL.md`。
- 命中类 2 / 类 4 时特别核对「净新增」定性：不得以"存量没有这种页面"为由改用其他形态顶替。
