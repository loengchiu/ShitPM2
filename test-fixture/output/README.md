# 输出测试夹具说明

`output/` 下的 Design 和 PRD 文件是历史产物与回归夹具，不是当前规则的唯一正例。

- `design/design.md`：历史设计稿，保留部分旧规则表达，用于回归和差异分析。
- `prd/prd.md`：历史综合 PRD 对照文件，保留部分旧规则表达，用于回归和差异分析。
- `prd/prd-5.1-skill-generated.md`：当前规则下的单模块正例，但不代表完整 PRD。
- `prd/prd-new-sample.md`：已明确标注的历史负例，不得作为生成模板。

读取测试夹具时，必须结合本说明和文件内标注判断其用途，不得把历史写法当作当前规则示例。
